# StudentManagementSystem
Mini Project: Student Management System

A console-based Student Management System developed using Core Java and Object-Oriented Programming concepts.

Technologies Used
Java (JDK 26)
IntelliJ IDEA
Git and GitHub

Features
1.Add a new student with ID, name, age, and marks.
2.Display all student records.
3.Search students by ID.
4.Update student details.
5.Delete student records.
6.Calculate grades based on marks.

Data Storage
Student records are stored in an ArrayList<Student> during program execution. This project currently uses in-memory storage and does not use a database.
